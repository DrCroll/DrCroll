I make FiveM scripts. Most of them are through **Croll Studio**, and some I throw up here for free when I'm feeling nice.

I mainly work with Qbox, ox_inventory, ox_target, and ox_lib -- but I build all my scripts to be opensourced so they fit any framework, inventory, and target system.

## Tech

`Lua` `FiveM` `Qbox` `QB-Core` `ESX` `ox_inventory` `ox_lib` `ox_target` `JS` `HTML / CSS`
