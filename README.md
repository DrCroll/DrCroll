# DrCroll

I make FiveM scripts. Most of them are through **Croll Studio**, and some I throw up here for free when I'm feeling nice.

I Mainly work with with Qbox, ox_inventory, ox_target and ox_lib. But I give all my scripts the ability to be opensourced to fit any, framework, inventory and target system

## Tech

`Lua` `FiveM` `Qbox` `QB-Core` `ESX` `ox_inventory` `ox_lib` `ox_target` `JS` `HTML / CSS`

## Free Stuff

| Repo | What it does |
|------|-------------|
| [Croll-Ammo](https://github.com/DrCroll/Croll-Ammo) | Custom Ammo boxes, that can be configurable to give anything with any amount |
